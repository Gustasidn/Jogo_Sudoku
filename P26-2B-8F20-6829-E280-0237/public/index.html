Sudoku com Validador e Cronômetro

Desenvolva uma plataforma de Sudoku que ofereça grades de desafios em três níveis de dificuldade. A interface em HTML e CSS Grid deve permitir a inserção de números definitivos e anotações de rascunho nas células, utilizando eventos de teclado e mouse gerenciados por JavaScript vanilla. O usuário deve autenticar-se com sua conta do Discord para iniciar um tabuleiro. Ao iniciar uma partida, uma Cloudflare Function registra o carimbo de tempo inicial no banco de dados D1 e entrega a matriz base ao cliente. O progresso intermediário pode ser salvo mediante requisição do usuário, e a submissão final é validada matematicamente no servidor na borda, que calcula o tempo total gasto e insere o resultado no ranking de velocidade daquele desafio específico.
